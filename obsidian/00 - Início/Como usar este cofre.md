# Como usar este cofre

Volte para a [[Home]] sempre que quiser se orientar.

## A regra das 4 perguntas (método PARA)
| Pergunta | Vai para |
|---|---|
| Tem **prazo e entrega final**? | `01 - Projetos` |
| É algo que preciso **manter sempre**? | `02 - Áreas` |
| É só para **consultar**? | `03 - Recursos` |
| **Já acabou** ou parou? | `04 - Arquivo` |

Exemplo: "Lançar a Laura Growth" é Projeto. "Marca e Posicionamento" é Área (existe enquanto o negócio existir).

## Convenções
- Cada nota começa com um bloco entre `---` (propriedades): `tipo`, `status`, `criado`.
- **Status:** `conceito` → `rascunho` → `em validação` → `aprovado`.
- Para ligar duas notas, escreva o nome entre colchetes duplos: `[[Modelo Comercial]]`.
- Cada pasta principal tem um índice: [[Índice - Projetos]], [[Índice - Áreas]], [[Índice - Arquivo]].
- Para criar uma nota nova a partir de um modelo, copie de `99 - Sistema/Templates`.

## Dica de navegação
- `Ctrl/Cmd + O` abre qualquer nota pelo nome.
- `Ctrl/Cmd + G` mostra o mapa de conexões (gráfico).
